## Редактирование и проверка

Проект — статический HTML/CSS/JS, без сборщика и внешних библиотек.

```sh
node verify.cjs
node export-offline.cjs
python -m http.server 8765
```

`verify.cjs` проверяет модель графа, 123 карточки, фильтрацию, поиск, геометрию и подсчёт опросов. Это проверка модели с имитацией DOM, она не заменяет визуальный просмотр сайта. `export-offline.cjs` обновляет автономный HTML после правок. Коммитить нужно и исходные файлы, и обновлённый `atlas-offline.html`.

Ответы на тесты живут только в памяти вкладки. Они не отправляются на сервер, не сохраняются в URL или localStorage. Переход между разделами сохраняет текущий прогресс; перезагрузка его удаляет.
