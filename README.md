# Атлас мысли — публикация на GitHub Pages

Архив atlas-github-pages.zip содержит готовый статический сайт. Сборка, Node.js, база данных, платный сервер и ключи API не нужны. Это редакция с интерактивным графом, 45 направлениями и персональными карточками философов.

1. Распакуйте архив на устройстве. На компьютере работать удобнее, но можно и через браузер Android.
2. Войдите на https://github.com и создайте репозиторий: https://github.com/new.
3. Назовите его `philosophy-atlas`, выберите **Public**, включите **Add a README file** и нажмите **Create repository**. Для публичных репозиториев GitHub Pages доступен на бесплатном тарифе. Исходный код и сам сайт будут публичными.
4. Откройте репозиторий → **Add file → Upload files**. Выберите все распакованные файлы сайта. Загружайте содержимое архива, а не ZIP и не папку, содержащую всё остальное. В корне должен лежать `index.html` рядом с `styles.css`, `river.css` и файлами JavaScript. Нажмите **Commit changes**. Инструкцию README из архива загружать необязательно.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, **Branch: main**, папку **/(root)** и нажмите **Save**.
6. Дождитесь публикации. В том же разделе Pages появится адрес и кнопка **Visit site**. Обычно адрес имеет вид `https://ВАШ-ЛОГИН.github.io/philosophy-atlas/`.

## Обновления

Загружайте новые версии файлов через **Add file → Upload files** и подтверждайте **Commit changes**. GitHub Pages опубликует новую версию автоматически. Старые варианты останутся в истории репозитория. При получении нового архива заменяйте весь набор файлов, чтобы код и данные были одной редакции.

## Если не открывается

- Убедитесь, что в выбранной папке лежит именно `index.html`, а не ZIP-архив или ещё одна вложенная папка.
- Проверьте ветку `main` и папку `/(root)` в Settings → Pages.
- Статус публикации и ошибки видны во вкладке **Actions**.
- Если сайт открылся со старым оформлением, обновите страницу с очисткой кэша или проверьте в приватной вкладке.

## Что переносится

Содержание, граф, фильтры, карточки, сравнение и компас полностью работают в браузере. Связи с ChatGPT и зависимость от подписки отсутствуют. Ссылки на внешние энциклопедии требуют интернета. Ответы в компасе не сохраняются после перезагрузки. Автономную копию можно скачать с самой страницы.

Старая ссылка ChatGPT Sites не перенаправляется автоматически: адрес GitHub Pages будет новым. Ни этот архив, ни инструкция сами по себе не создают репозиторий и не публикуют сайт в вашем аккаунте.

## Файлы

- `index.html` — страница.
- `styles.css`, `river.css` — оформление.
- `data.js`, `enrichment.js` — течения, исторический контекст и источники.
- `graph-data.js` — представители, их тезисы и редакционная структура карты.
- `app.js`, `river.js` — карточки, граф, поиск, фильтры, сравнение и компас.
- `atlas-offline.html` — автономная версия, которую можно открыть без интернета.

Размеры узлов и толщина связей — редакционные акценты, а не количественные измерения философской значимости. Ленты связывают направления, не всех представителей попарно. Узлы сгруппированы по направлениям, а не по датам жизни. На маленьком экране карта открывается около Хайдеггера; кнопка «Вместить» показывает весь граф.

Проверены модели всех фильтров, персональные карточки, поиск, масштабирование и структура SVG. Полная проверка в реальном браузере в этой среде не выполнялась.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
